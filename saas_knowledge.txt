# B2B 电商履约与物流追踪 SaaS 内部知识库 (最后更新: 2026-03-03)

## 第一部分：标准排查操作指南 (SOP) 与 API 接入文档

### SOP-001: 身份验证与授权失败排查
- 现象：商家反馈接口一直返回 HTTP 401 Unauthorized 或 403 Forbidden。
- 排查链路：
  1. 检查 API 密钥是否过期。免费版商家的 Token 有效期为 90 天。
  2. 【高频错误】遇到 `HMAC validation failed` 验签失败或 401 错误，通常是商家在 Shopify 后台安全设置中重置了 API Token，但未在我们的系统后台重新绑定。请引导商家进入“设置->授权管理”点击重新授权。
  3. 如果是 403 错误，且提示 `scope_lacking`，说明商家未在 Shopify 应用商店勾选 `read_orders` 或 `write_fulfillments` 权限。

### SOP-002: Webhook 回调异常处理
- 现象：商家表示订单发货后，没有收到我们的 Webhook 状态推送。
- 排查链路：
  1. 检查商家的接收服务器状态。如果我们的推送日志显示 502 Bad Gateway 或 504 Gateway Timeout，属于商家自身网关问题，直接提供日志截图让商家自行修复。
  2. 我们的 Webhook 要求商家的接口在 3 秒内返回 HTTP 200 状态码。如果返回 201 或其他状态，系统会判定推送失败并进入重试队列（最多重试 5 次）。
  3. 请确保商家在接收回调时，正确解析了 payload 中的 `tracking_number` 字段。

### SOP-003: 物流商 API 限流规则
- 说明：为了防止被物流商封禁 IP，系统对各渠道查询频率有限制。
- 顺丰国际 (SF Express)：每分钟限查 500 票。
- 联邦快递 (FedEx)：每分钟限查 300 票，超出返回 429 Too Many Requests。

## 第二部分：近期发版记录 (Release Notes)

### 2026-03-02 [v2.4.1] 紧急热修复 (Hotfix)
- 修复了因为闰年计算错误，导致 2 月 29 日生成的订单在前端界面显示为 3 月 1 日的展示 Bug。
- 回滚了昨天上线的“智能预估送达时间(ETA)”模型，因为发现部分欧洲偏远地区的 ETA 预估过于激进。

### 2026-03-01 [v2.4.0] 核心模块重构与功能上新
- 【重磅】上线了全新的批量导出订单 UI 逻辑，将原先悬浮在底部的导出按钮，移至右上角“更多操作”下拉菜单中。
- 【重构】重构了 USPS 和 FedEx 的物流轨迹抓取爬虫模块。引入了全新的动态代理池，并增加了一层极其严格的限流校验（Rate Limit）。注意：该重构可能导致部分老旧状态的运单（尤其是状态停留超过 30 天的）卡在“已发货”状态不再更新，如有客诉请引导商家手动点击“强制刷新”。
- 【优化】优化了 Shopify webhook 接收延迟，从平均 1.5 秒缩短至 0.8 秒。

### 2026-02-15 [v2.3.9] 支付模块升级
- 移除了对旧版 PayPal 支付网关的支持。

## 第三部分：已知缺陷库 (Known Issues / Jira Backlog)

### JIRA-1042: RTL 语言订单同步超时
- 缺陷描述：当商家同步带有阿拉伯语、希伯来语等 RTL (Right-to-Left) 语言地址的 Shopify 订单时，特定字符（如连字符和特殊空格）会导致后端 JSON 解析引擎陷入死循环，最终引发 504 接口超时报错。
- 临时方案 (Workaround)：建议商家在 Shopify 端将客户地址手动转为纯英文拼音后再进行同步。
- 状态：已定位根因，排期至 v2.5.0 版本修复。

### JIRA-0899: 超大组合商品 (Bundle) 运费计算内存溢出
- 缺陷描述：当一个单一订单中的 SKU 超过 50 个，且包含不同体积重的组合商品时，在调用跨国物流运费试算接口时，会发生 OOM（内存溢出）导致计算失败，界面提示“运费计算服务不可用”。
- 临时方案 (Workaround)：无代码级修复方案。客诉时请客服建议商家将超大订单分拆为 2-3 个子订单进行履约。
- 状态：已知架构瓶颈，短期内不予修复 (Won't Fix)。

### JIRA-0755: 导出 PDF 乱码
- 缺陷描述：商家在导出月度物流账单 PDF 时，如果商家名称包含 emoji 表情，生成的 PDF 文件中 emoji 会显示为黑色方块或乱码。
- 状态：低优先级，观察中。
